# VRM 読み上げペイン

## 2026-10-25

### 経緯

非公開のアプリ nakamura196/vrm-script-reader-next（VRM のアバターが台本を読む）を、awase のペインとして移した。
元のアプリは、あらかじめ作った台本 JSON（音声ファイルと口形素 viseme つき）を再生していた。

### 決めたこと

- **音声はブラウザの音声合成（Web Speech API）にした。** 事前に音声を作らなくても、発話（sp・said）のある TEI なら何でも読める。
  代わりに口は「開閉」だけで、口形素には合わせない（話している間の振動と、`onboundary` での開きの強調）
- **同梱するのは boy.vrm（約 20MB）だけ。** girl.vrm（27MB）は載せない。`vrm=<URL>` で別のモデルを指せる
- **panes を書かないときは出さない（オプトイン）。** 20MB を読むため。`panes` に `vrm` を明示したときだけ出す。
  そのため `togglePane` は、書いていない状態から vrm を出すと、ほかのペインも全部書き出す
- three と @pixiv/three-vrm（3.5.5 に固定）は、ペインが出たときに動的に読み込む
- 読み上げの声は、TEI の xml:lang（text、ルートの順）、無ければ画面の言語で選ぶ

### 確かめたこと・確かめていないこと

- 純粋な部分（声の選び方、言語の決め方、発話の送り方、panes の出し入れ）は vitest で確かめた
- 画面の出し入れは Playwright で確かめた。ヘッドレスでは WebGL が使えない場合があり、アバターの描画そのものは目で確かめていない部分がある
- 実際の VR 機器では試していない
- 声は OS・ブラウザで違う。日本語の声が無い環境では既定の声になる
