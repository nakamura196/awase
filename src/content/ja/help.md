# ヘルプ

Awase（合せ）は、TEI をまとめて読む統合ビューアです。本文・注釈・画像・地図を、一つの画面に合わせて表示することを目指しています。

いまは骨組みだけを置いた段階で、各画面は準備中です。

## 画面

- [ビューア](../viewer/): TEI の本文を、画像や注釈と並べて読みます。
- [比較](../compare/): 二つの資料や諸本を並べて見比べます。
- [XSL](../xsl/): XSLT で TEI を変換し、見え方を試します。
- [DTS](../dts/): DTS（Distributed Text Services）の文書を一覧し、開きます。

各画面は、開く資料や設定を URL のクエリ（`?` 以降）で受け取る予定です。準備中の画面には、受け取る予定のパラメータの一覧が出ます。
